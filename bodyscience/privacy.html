개인정보처리방침

시행일: 2026년 11월 2일

1. 대상

fit-uploader는 '몸의 과학' 유튜브 채널 운영자가 자신의 채널에 영상을 업로드·예약하고 채널 통계를 확인하기 위해 만든 개인용 도구입니다. 운영자 본인 외의 사용자는 이용하지 않습니다.

2. 이용하는 정보

운영자 본인의 Google 계정 승인으로 YouTube Data API를 통해 운영자 채널의 영상 업로드, 재생목록 관리, 채널·영상 통계 조회만 수행합니다. 시청자나 다른 사용자의 개인정보는 수집하지 않습니다.

3. 보관과 제3자 제공

인증 정보는 운영자의 비공개 저장소 비밀값에만 보관하며, 제3자에게 제공·판매하지 않습니다. Google API 서비스에서 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

4. 권한 철회

myaccount.google.com/permissions 에서 언제든 앱 접근 권한을 철회할 수 있습니다.
