여행책 편집기 NAS의 2026_마카오_돼지사냥꾼 폴더를 열어 주세요

처음 쓰는 방법

  1. 집 PC에서 파일 탐색기 → 주소창에 \\192.168.219.112 입력 → 2026_마카오_돼지사냥꾼 폴더가 보이는지 확인 (NAS 아이디로 로그인)
  2. 이 화면에서 📂 NAS 폴더 열기 → 그 폴더 선택 → ‘파일 보기 허용’, 내보낼 때 ‘변경사항 저장 허용’
  3. 위에서 판을 고르면 그 집 기준으로 사진·후기가 다시 배치됨
  4. 고치기: 사진 클릭 = 같은 일정의 다음 후보 사진으로 바꿈 · 후기 카드 클릭 = 빼기/다시 넣기 · 오늘의 한 줄 클릭 = 다른 후기로 · 장 표지 클릭 = 다른 표지 사진
  5. 💾 편집 저장 → NAS 06_결과물/책_원고/편집.json에 저장 (다음에 열어도 그대로)
  6. 🖼 JPG 내보내기 → 06_결과물/책_JPG/판이름/에 쪽별 JPG(2468×2468, 도련 3mm 포함) 저장 → 퍼블로그에 순서대로 올림

필요한 파일: 06_결과물/책_사진/photos.json(정리 스크립트), 06_결과물/책_원고/ 안의 앱 백업 JSON, 단톡_인용.json. 사진과 글은 이 PC 안에서만 처리되고 어디에도 올라가지 않음.
