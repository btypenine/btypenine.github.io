📦 쓰던 일정 옮기기 웹앱 → 앱

예전에 인터넷 주소나 「홈 화면에 추가」로 쓰던 일정은 아래 방법으로 옮김.

✅ 새 앱을 열었을 때 일정이 그대로 보이면 옮길 필요 없음
(크롬에서 쓰던 경우 같은 저장 공간을 써서 그대로 보일 수 있음)

일정이 안 보이면 — 백업 복사 → 붙여넣기

① 예전 웹앱→⚙ 설정→📋 백업 복사
② 새 앱(9 아이콘)→⚙ 설정→📥 백업 붙여넣기→가져오기
⚠ 새 앱에서 일정이 다 보이는지 확인한 뒤에 예전 홈 화면 바로가기를 지울 것

🔄 업데이트

  • 화면·기능 개선은 앱을 열 때 자동 반영 — 다시 설치할 필요 없음
  • 앱 이름·아이콘이 바뀌는 경우만 이 페이지에서 새 파일을 받아 덮어쓰기 설치(일정 유지)

아이폰은 설치 파일 없이 사용. 사파리로 아래 버튼 → 공유(□↑) → 홈 화면에 추가.
